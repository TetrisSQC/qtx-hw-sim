# LC-80 (Lerncomputer G-5403.500, boards 15403.500-1901 and -1902 keyboard), captured by hand
# from lc80/schaltplan_lc80.jpg (scan since deleted). Only fitted parts ("n.b." = not fitted: ROM3-5, RAM2-4 left out;
# their selects /ROM3../RAM4 stay on the decoders). Power supply, tape amplifier and the bus
# connectors X1/X2 are not captured; the tape input is the B861's pull-up R283.
#
# Format:  REF  TYPE  X  Y  pin=NET ...      (X Y in mm on a synthesized board)
#
# Readings that are interpretations, not plain lines on the scan:
# - the bus wires are numbered per bus: address 0-15 = A0-A15, data 0-7 = D0-D7, the control bus
#   0-7 = /M1 /IORQ /RD /WR /MREQ /RFSH /HALT /BUSAK (CPU outputs), 8-14 = /INT /NMI /BUSRQ /WAIT
#   /RESET CLK CLK2, 15/16 = SEL15/SEL16 (pulled up by R318/R317, switch KSD11 not fitted),
#   17 = M1P (M1 for PIO/CTC, also low during RESET), 18-26 = chip selects, 27 = +5V,
#   28/29 = the interrupt daisy chain (CTC -> user PIO -> system PIO)
# - D209 E2 / D210 E2 "4" = /MREQ (control bus), not A4
# - I/O selects are linear: system PIO /CE = A3 ($F4-$F7), user PIO /CE = A2 ($F8-$FB),
#   CTC /CE = A4 ($EC-$EF); B/A = A0, C/D = A1 (CTC CS0/CS1 = A0/A1)
# - the RC oscillator (D211 13->12 with C348/C248, R272/R321/V218) is driven by the machine on OSC
